Insert Typeface Samples into Supabase

⚠️ Database Setup Required:

Before running this script, make sure you have created the typeface_samples table in Supabase with the following schema:

  • id - UUID (primary key, auto-generated)
  • family_name - TEXT (unique)
  • sample_texts - TEXT or JSONB (stores JSON array of sample objects)
  • created_at - TIMESTAMP
  • updated_at - TIMESTAMP

See TYPEFACE_SAMPLES_SCHEMA.sql for the SQL to create this table.

ℹ️ Instructions:
  1. Make sure you have the Supabase client configured in supabase-config.js
  2. Create the typeface_samples table in your Supabase database
  3. Click the button below to insert/update all typeface sample texts
  4. Check the output area for results
