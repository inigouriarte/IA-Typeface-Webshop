Tutorial

Getting started

Welcome to the Indigo Alphabets admin panel. Here you can manage your typefaces, page content, visual styles and orders.

Navigation: Use the sidebar on the left to switch between sections. Each section saves independently via its own Save button.

Fonts

Font list: Drag cards to reorder (this controls homepage display order). Click "Save order" to persist. Click a card to open the editor.

Font editor: Edit all aspects of a typeface: basic info, description, homepage sample text, hero section, detail data, pricing, OpenType features and font files. Changes are not saved automatically — click "Save" or press ⌘S when ready.

New font: Provide a font ID (lowercase slug), family name, directory name, and upload .woff2/.woff files. The system auto-detects weights from filenames.

Page content

Edit text for all pages: Homepage, About, Contact, Licensing, and legal pages (Privacy Policy, Impressum, Terms, Withdrawal).

Use the tabs to switch between pages. You can add, reorder (drag), rename and remove paragraphs within each page. Each paragraph has a name label and a text area.

Click Save Content when done. Changes are not saved until you press the button.

Styles

Control the visual tokens used across the website: colours (light and dark mode), typography (font families and sizes) and layout (margins, box dimensions).

Colour pickers sync with hex inputs. Changes are applied after saving.

Deploying changes

Saving here writes your content to the data store, but the live site is static HTML generated from that data at build time \u2014 saving alone does not update indigoindigo.org.

To publish a change: the site's build script needs to run and the result needs to be pushed to the main branch. Vercel then deploys automatically, typically within 30\u201360 seconds.

Orders

View all Stripe orders. Use the search bar and dropdown filters to find specific orders. Click "Export CSV" to download the full list.

Orders are fetched from Stripe directly. If Stripe is not configured, this section will show a placeholder.
